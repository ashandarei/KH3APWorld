# Stats and bonuses

Your host can change how Sora grows and how equipment and meals affect your
stats. These choices are made when creating a run.

- **Base stats** change Sora's starting stats.
- **Level-up stats** change the stat increases earned while leveling.
- **Keyblade stats** change Keyblade strength and magic bonuses.
- **Equipment stats** change the bonuses on armor and accessories.
- **Food effects** change the bonuses from meals.

Read each option's description in your player settings before choosing it.
Changing stat bonuses does not create extra Archipelago checks. Equipment
abilities and minigame rewards have their own
[separate settings](equipment-and-minigame-pools.md).

Ask your host for a new run if you want different starting options. Use the
[setup guide](setup_en.md) when switching runs.
