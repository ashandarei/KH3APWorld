# Hosting Kingdom Hearts III

You can host a KH3 room without owning or installing KH3. Players who join
with KH3 need their own copy of the game and the KH3 player download.

## Choose your download

| Download | Choose this if… |
| --- | --- |
| **Player APWorld** | You will play KH3. It also includes everything needed to generate and host rooms. |
| **Host APWorld** | You only need to generate or host rooms. It leaves out the files needed to play KH3. |

Install your chosen `kh3.apworld` through **Install APWorld** in the
Archipelago Launcher, then restart the launcher. Install one KH3 package at
a time. Hosts and players should use the same KH3 world version.

## Create and host the room

1. Collect each player's settings file (their `.yaml` download).
2. Generate the room as usual, using **Kingdom Hearts III** for KH3 players.
3. Host the generated room through your usual Archipelago hosting method.
4. Give each player the server address, their exact player name, and the
   password if you set one.

KH3 players follow the [setup guide](setup_en.md) and connect with KH3 closed.
Their client normally gets the player file and prepares the game automatically.
If a player needs a file directly, give them their own `.apkh3` download and
have them use **Import Seed Pak** in Save Manager.

The Host APWorld cannot patch or launch KH3. Use the Player APWorld if you
also want to play.

## Race rooms

When generating a race, enable Archipelago's **Race** setting and turn off
spoiler output. These are room-generation settings, separate from each
player's KH3 settings.

In a race, rewards stay hidden until the server sends the item. Players
should keep their KH3 client connected. Secret Report hints are disabled;
other Archipelago hints follow the room's hint settings.

Keep the full room download and server files private. Share only each
player's own file, never the organizer's complete archive or spoiler files.
