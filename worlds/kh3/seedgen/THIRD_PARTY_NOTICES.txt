KH3 Python seed generator
=========================

The game-specific generation rules were ported and adapted from
WaterKH/KH3RandomizerClient (https://github.com/WaterKH/KH3RandomizerClient),
licensed under the Apache License, Version 2.0, and the former modified C# integration
in this repository. The Python port includes Archipelago-specific modifications.
See ../LICENSE-KH3RandomizerClient.txt for the complete license,
../THIRD_PARTY_NOTICES.txt for the attribution and modification notice, and
../UPSTREAM-KH3RandomizerClient-CREDITS.txt for the upstream credits.

The Python implementation has no third-party runtime dependencies. Python's
standard-library json is its sole JSON implementation.

The cooked asset format implementation was informed by these format references
and checked against their readers:

* waterkh/UE4DataTableInterpreter
  https://github.com/waterkh/UE4DataTableInterpreter
  Apache License, Version 2.0

* atenfyr/UAssetAPI
  https://github.com/atenfyr/UAssetAPI
  MIT License, copyright (c) 2020 - 2026 atenfyr

These projects were used as development references.
