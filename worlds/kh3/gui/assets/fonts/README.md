Roboto Regular, Bold, Italic, and Bold Italic are unmodified copies of the font
assets shipped with the existing client's KivyMD 2.0.1.dev0 installation.
Copyright 2011 Google Inc. Licensed under Apache License 2.0; see LICENSE.txt.
Upstream: https://github.com/googlefonts/roboto-2

These standalone font assets let the native client share the existing typeface
without importing or requiring Kivy/KivyMD. Windows registers them privately
for this process; they are not installed in the user's system font collection.
