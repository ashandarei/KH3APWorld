# KH3 client artwork

`kh3-icon.png`, `kh3-icon-32.png`, and `kh3-icon-16.png` are size variants of
the user-provided `D:\Images\kh3 icon.png`, with its aspect ratio and transparency
preserved. The 256-pixel image is also registered for the KH3 Client entry in
the Archipelago launcher. Runtime loading uses packaged resources, not that
machine-specific source path.

Roboto font attribution and licensing are in `fonts/README.md` and
`fonts/LICENSE.txt`; that font license does not apply to this artwork.
