# Music development

The canonical [native music reference](../../../KH3Runtime/docs/MUSIC_DEVELOPMENT.md)
owns format limits, target precedence, manifest examples, decoding/lifetime rules
and native tests. Follow its runtime-root build commands; `KH3_RUNTIME_DIR`
selects another checkout when the usual sibling layout is unavailable.

Use [Music and custom songs](../../worlds/kh3/docs/music.md) for player setup and
[Now Playing](now_playing/README.md) for overlay behavior.
